# FLW Engine Adapter Notes

This folder captures how FLW might talk to the underlying VDO Ninja engine without coupling UI code to the existing UX. It is intentionally documentation-only so far.

- `flw-video-contract.md` documents the high-level contract and host controls we need for v1.
- `vdo-adapter-notes.md` lists the VDO engine objects and entry points we expect to call, with open questions for unknown behaviors.
