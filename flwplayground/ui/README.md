# FLW Prototype Shell

This folder contains a lightweight HTML/CSS/JS shell for FLW-styled video controls and placeholders.

- `prototype-shell.html` – entry point with local preview, participants list, controls, and debug events panel.
- `prototype-shell.css` – simple theming to keep the FLW aesthetic.
- `prototype-shell.js` – stub-first logic: buttons log events, host controls are placeholders, and future VDO runtime scripts can be referenced.

Open `prototype-shell.html` in your browser locally (double-click or via `live-server`) to see the prototype.
